## Cómo trabajo

- **Celular primero.** Todo se diseña para el teléfono.
- **Hecho para el dominicano.** Español dominicano, RD$, ITBIS 18 % y horas de 12 h.
- **Automatizar, no dar trabajo.** Si el sistema puede deducir un dato, no se lo pide al usuario.
- **Documentado.** Cada proyecto tiene `README.md`, `AGENTS.md` y `CHANGELOG.md` para que cualquier persona o agente de IA entienda y mantenga el código. El contexto general está en [CONTEXT.md](https://github.com/Mingo20/dtech/blob/main/CONTEXT.md).
